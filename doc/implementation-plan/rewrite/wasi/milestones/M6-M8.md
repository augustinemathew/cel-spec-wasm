## What landed

### M6-scoped subset — WASI stub for `random_get`

`eval/engine.cc`: added a 30-LoC stub for
`wasi_snapshot_preview1.random_get(buf, len) -> errno`.

wasi-libc's dlmalloc seeds itself via `random_get` on the
first allocation.  Without the stub, the runtime module
fails to instantiate with `unknown import:
wasi_snapshot_preview1::random_get`.

The stub zero-fills the buffer and returns success.  We
don't need actual randomness — the runtime is deterministic
by design (same expression + same activation => same bytes).
A future Phase C work might want a real `getrandom` if RE2
relies on hash randomisation; until then, zeros are safe.

Registered via `RegisterWasiStubs(impl->linker)` in
`InitLinker`, alongside the existing `cel_log` and
`cel_host_*` registrations.

### M6 (partial) — keep host memory ownership for now

The DESIGN says the runtime should OWN memory (export it).
The compat path keeps the original setup: host allocates
memory via `wasmtime_memory_new`; runtime imports it via
`-Xlinker --import-memory=cel,memory`.  Switching to
runtime-owns-memory triggers two-memories-confused: host
writes go to memory A, runtime writes to memory B, decoder
reads from A and sees nothing.

`runtime/BUILD.bazel` was briefly switched to
runtime-owns-memory (no import-memory flag) but reverted
after `m4_test` started failing with `kind=0` results (the
runtime's writes were invisible to the host's reads).

**M6 will be properly flipped in Phase B** when we also
update `engine.cc` to pull memory from `runtime_instance`.
For Phase A MVP, the host-owned memory path stays.

## Plan-vs-execution deltas

  - **M5 (codegen prologue swap) skipped.**  Codegen still
    emits `(call $cel_reset arena_base mem_size_bytes)`.
    Compat shim routes through.  Saves ~1 day of codegen
    test rebaselining for an MVP that doesn't strictly
    require it.  Codegen prologue swap moves to Phase B.
  - **M7 (host_string_arena deletion) skipped.**  Activation
    marshalling still uses the old `EnsureHostStringArenaCapacity`
    path — that bookkeeping costs ~110 LoC but doesn't break
    anything functional.  Deletion moves to Phase B.
  - **M6 (host memory ownership flip) skipped.**  Host still
    allocates memory; runtime still imports it.  Flipping
    causes two-memories breakage that needs a coordinated
    engine.cc rewrite (Phase B).
  - **Net of skips**: the MVP works without M5/M6/M7's
    invasive changes.  The simplification dividend is paid
    in Phase B; for now we get library-compatible malloc +
    the bump-arena perf via the compat shim.
