# M2 — runtime/BUILD.bazel switch to wasi-sdk + cel_layout.h

Status: **shipped 2026-05-18.**

## Acceptance

`bazel build -c opt //runtime:cel_runtime_wasm_file`
produces a working `cel_runtime.wasm` using wasi-sdk's clang
targeting `wasm32-wasi`.

Measured:
  - Binary: **241,411 B stripped / 53,681 B gzipped** (baseline
    was 60,971 / 11,741 — so +180 KB stripped, +42 KB gzipped
    for wasi-libc + dlmalloc + libc++ machinery).
  - Imports: 14 (13 cel_env/cel_host as before + 1 new
    `wasi_snapshot_preview1.random_get`, pulled in by dlmalloc's
    seed; browser-shimmable good-subset import).
  - Memory exported by default (no explicit
    `--export=memory` needed under wasm32-wasi).
  - `__heap_base` exported as a wasm global — host can read for
    the A14 layout check.
  - `arena_init`, `arena_alloc`, `arena_reset`, `arena_cursor`,
    `arena_capacity`, `malloc`, `free`, plus the
    `cel_alloc` / `cel_reset` compat shims all exported.

## What landed

1.  **`runtime/BUILD.bazel`** updated:
    - Clang path: `/opt/homebrew/opt/llvm/bin/clang` →
      `$(execpath //third_party/wasi_sdk:clang)`.
    - Target: `wasm32` → `wasm32-wasi`.
    - Dropped `-ffreestanding -nostdlib` (wasi-libc supplies
      libc + libc++).
    - Added `-nostartfiles` (runtime is library code; no main).
    - Dropped `-Xlinker --import-memory=cel,memory` (runtime
      now owns + exports memory).
    - Added `-Wl,--global-base=8192` (reserves `[0, 8192)` for
      expr-module rodata per DESIGN §3).
    - Added exports: `__heap_base`, `malloc`, `free`,
      `arena_init`, `arena_alloc`, `arena_reset`,
      `arena_cursor`, `arena_capacity`.
    - Kept exports: `cel_alloc`, `cel_reset` (compat shims).
    - Added `tools = ["//third_party/wasi_sdk:clang"]`.
    - Added `cel_layout.h` to the genrule srcs + native cc_library hdrs.

2.  **`runtime/cel_layout.h`** (NEW, 50 LoC):
    Single header with the magic numbers — initial pages,
    reserved low region, arena capacity, wasm page size.
    Codegen + host + runtime all `#include` this; drift between
    them caught at compile time.  Includes asserts A5-A7 from
    DESIGN.md §5.

3.  **`runtime/cel_memory.c`** native build:
    Bumped `CELWASM_ARENA_BYTES` from 64 KiB → 128 KiB so the
    arena's backing buffer (`g_memory + 16`) fits with the
    default capacity.

## Plan-vs-execution deltas

  - **`--export=memory` rejected by wasm-ld.**  In freestanding
    mode it works; in wasi-sdk mode, memory is exported by
    default (per `exp_c_malloc.wasm`'s output).  Just removed
    the line.

  - **`tools=` not `data=`.**  Genrules that invoke a binary
    use `tools=`; that's how `$(execpath ...)` resolves the
    correct path.
