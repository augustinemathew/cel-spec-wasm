# `doc/` — documentation index

The map of the cel-wasm documentation tree, routed by what you're here
to do.

> **Live numbers live in code, not here.**  The authoritative
> conformance headline (pass/skip/fail) is the autogenerated block in
> [`../conformance/README.md`](../conformance/README.md).  Pass-counts
> quoted in milestone docs are point-in-time snapshots from when that
> milestone shipped — historical, not current.

## Design history

How the system got its shape — per-milestone plans and superseded
designs, kept for the record:

| Where | What it is |
| --- | --- |
| [`implementation-plan/rewrite/`](implementation-plan/rewrite/) | One `mNN-<slug>.md` per milestone (m1 scalar pipeline … m28 configurable linking), plus feature/sub-feature plan docs.  Each carries a status header (`shipped <date>` / `plan` / `superseded`). |
| [`implementation-plan/rewrite/wasi/`](implementation-plan/rewrite/wasi/) | The WASI / malloc-migration workstream; `DESIGN.md` is authoritative for the shared-memory + malloc-arena shape. |
| [`implementation-plan/rewrite/phase-c-design.md`](implementation-plan/rewrite/phase-c-design.md), [`phase-c-plan.md`](implementation-plan/rewrite/phase-c-plan.md), [`phase-c-probes/`](implementation-plan/rewrite/phase-c-probes/) | The in-runtime-libraries phase (RE2, absl::time) — shipped; historical build plans + probe results. |
| [`implementation-plan/rewrite/wat/`](implementation-plan/rewrite/wat/) + [`wat-traces.md`](implementation-plan/rewrite/wat-traces.md) | The assembled-and-run WAT trace set, one per codegen arm (memory offsets in the narrative are pre-Phase-C — see the banner). |
| [`implementation-plan/rewrite/archive/`](implementation-plan/rewrite/archive/) | Superseded predecessor designs. |
| [`implementation-plan/rewrite/reviews/`](implementation-plan/rewrite/reviews/), `m13-reviews/`, `wasi/reviews/` | Dated code-review reports. |
