# Single source of truth for symbols exported by cel_runtime.wasm.
#
# Read at build time by `//compiler_v2/runtime:wasm_export_args`
# (genrule below) — that target emits one `--export=<name>` line
# per symbol into a wasm-ld response file, consumed by the
# `cel_runtime_wasm.bin` cc_binary via `-Wl,@<rsp>`.
#
# Read at test time by `//compiler_v2/abi:runtime_catalogue_consistency_test`
# — that test asserts the [codegen-helpers] section's name set is
# IDENTICAL to `celwasm::abi::CelRuntimeHelpers()`.  Drift fails
# at PR time, not at wasmtime instantiate time.
#
# Format:
#   - One symbol per line.  Whitespace-only and `#`-prefixed lines
#     ignored.
#   - Section header `[<name>]` on its own line starts a new
#     bucket.  Two buckets exist: `codegen-helpers` (mirror of the
#     catalogue) and `host-only` (everything else — system /
#     linker-internal / native-test-only / `_arena` tail-call
#     targets that ride the linker through this file rather than
#     through the catalogue).
#
# When adding a runtime helper:
#   1. Add the catalogue entry in
#      `compiler_v2/abi/runtime_catalogue.cc` (arity, return shape).
#   2. Add one line in this file's [codegen-helpers] section.
#   3. Add the impl in `compiler_v2/runtime/cel_*.c`.
# Three edits, full stop.  The genrule + consistency test catch
# any inconsistency at build / test time.

# Symbols exported by cel_runtime.wasm that are NOT codegen-imported
# helpers.  Three sub-buckets:
#
#   - system / linker-internal: required for the wasi-sdk toolchain,
#     not present in the catalogue because codegen never references
#     them by name.
#
#   - public arena API for host reentry: the engine calls these
#     directly via the WasmtimeArenaAllocator and host-reentry path
#     (activation marshalling).  Distinct from the catalogue's
#     `arena_alloc` / `arena_reset`, which codegen imports for the
#     comprehension / list-builder prologue.
#
#   - same-kind eq/ne fast paths + `_arena` tail-call targets:
#     internal to the wasm module's dispatcher pattern.  Codegen
#     calls the polymorphic dispatcher (`cel_equals_at_vv`,
#     `cel_list_size`, …); the dispatcher tail-calls into one of
#     these.  Exported so native-host tests (`compiler_v2/runtime:
#     cel_*_test`) link against them directly.
